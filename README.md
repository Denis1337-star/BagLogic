# BagLogic

Прототип системы **лута и инвентаря**   

## Что сделано

- Предметы на ScriptableObject: категория, вес, стопка, способ подбора, рецепт разборки
- Инвентарь с лимитом по весу 
- Подбор: автоматически и по клавише E
- Подсветка лута
- UI инвентаря сеткой (Tab), разборка по клику при наличии рецепта
- HUD-сообщения при отказе, подсказка «E — предмет»
- Архитектура: MonoBehaviour-оболочки + обычные C#-классы, UI (MVP)
